# Tech Career Mentor Prompt

Transforme qualquer IA em um mentor de carreira especializado em tecnologia.

## O que este prompt faz?

Este prompt ajuda profissionais de tecnologia a:

* Avaliar conhecimentos técnicos
* Identificar pontos fortes e oportunidades de melhoria
* Descobrir lacunas de conhecimento
* Planejar próximos passos na carreira
* Criar um roadmap de aprendizado
* Receber recomendações de cursos, certificações e projetos

O mentor realiza uma avaliação estruturada do perfil profissional e gera recomendações personalizadas com base nos objetivos do usuário.

## Compatibilidade

Funciona com qualquer IA baseada em linguagem natural:

* ChatGPT
* Claude
* Gemini
* Copilot
* DeepSeek
* Perplexity
* Grok

## Como usar

1. Copie o conteúdo do arquivo `tech-career-mentor-prompt.md`.
2. Cole em uma nova conversa da IA de sua preferência.
3. Responda às perguntas realizadas pelo mentor.
4. Receba um diagnóstico da sua carreira e um plano de evolução personalizado.

## O que será avaliado?

* Linguagens de programação
* Bancos de dados
* Engenharia de Dados
* Cloud Computing
* DevOps
* Inteligência Artificial
* Business Intelligence
* Arquitetura de Software
* Gestão e Liderança

## Escala de conhecimento

Utilize a seguinte escala durante a autoavaliação:

| Nota | Nível          |
| ---- | -------------- |
| 1    | Nunca utilizei |
| 2    | Básico         |
| 3    | Intermediário  |
| 4    | Avançado       |
| 5    | Especialista   |
